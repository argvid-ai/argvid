# Protocol agent instructions

- Read `protocol/README.md`, `protocol/VERSIONING.md`, and the relevant RFC before editing.
- A schema change is incomplete without valid and invalid fixtures.
- State whether a change is additive, clarifying, behavioral, or breaking.
- Never introduce device-specific actuator commands into a public contract.
- Run the protocol and conformance checks and report compatibility evidence.
- Projects reuse root contracts; do not copy protocol/schema into project directories.
- The current pre-alpha stage is unversioned, not a released compatibility guarantee.
