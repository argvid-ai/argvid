# Start here

When delivered inside the Argvid repository, first follow root `START_HERE.md` → `AGENTS.md` → `PROJECT_CONTEXT.md` → `docs/ARCHITECTURE.md` → `BRIEF.md`. Then read this project's [README](README.md), [PROJECT_CONTEXT](PROJECT_CONTEXT.md), [BRIEF](BRIEF.md), [manifest](project.yaml), [architecture](architecture.md), [THIRD_PARTY](THIRD_PARTY.md), and [verification](docs/verification.md), followed by applicable root RFC/ADR and the specific task scope (Issue or task brief).

For standalone local use, this directory contains all application source, build instructions, synthetic fixtures, tests, and dependency identities. Read [setup and commands](README.md#setup). You need JDK17/Android SDK36, not a runtime account, API key, or unpublished schema.

Agents must preserve the six-layer/four-plane mapping. Project-specific simulator models and Room storage schemas do not define the canonical L2 protocol. Root RFC and conformance review govern any future shared contract. Local experimentation does not activate an accepted upstream project; publication/IP and device operations require their applicable authority.
