# Project documentation

Document public setup, usage, architecture choices, limitations, and reproducible handoffs here. Use [the generic task/report fields](../../../docs/TASK_HANDOFF.md): task/source revision, changed paths, tests/evidence, not-run checks, local/remote Git state and PR link, interface compatibility, blockers, next action, and required decision. Include applicable device/firmware/build versions. Keep credentials, unpublished context, full chats, and Agent prompts out of docs and logs. Reports with recipient/personnel details stay outside the repository. Root RFC/ADR review governs shared contract changes.
