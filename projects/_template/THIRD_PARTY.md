# Third-party and data review

No third-party dependencies, weights, datasets, media assets, or hardware design sources are included in this proposed template. Its source/documentation license is Apache-2.0 and fixture policy is synthetic-only. Review remains required before adding any such material.

For each addition in an activated project, record name, public source URL, immutable version/revision, license, copyright/notices, permitted use and redistribution, data provenance, publication rights, modifications, and human review evidence. Distinguish source code, model weights, data, assets, and hardware licenses.

Do not treat a code license as a dataset/weight/hardware license. Unknown rights stop publication. No credentials or personal/restricted media belong here. See [publication policy](../../docs/PUBLICATION_POLICY.md).
