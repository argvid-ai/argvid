# Public projects

This directory holds complete, self-contained public project deliveries approved under [repository scope](../docs/REPOSITORY_SCOPE.md). It currently contains only [a proposed template](_template/README.md), not an activated app/device implementation.

Activate a project through an approved Ready Issue, then follow [project requirements](../docs/PROJECTS.md). Every project preserves root contracts, maps all six layers/four planes, documents existing entrypoints and actual verification, and records license/data provenance. Do not copy root protocol schemas into a project.

Run `make project-check` for all projects or `./tools/project-check projects/_template` for the template. Publication review is required before the first public push.
